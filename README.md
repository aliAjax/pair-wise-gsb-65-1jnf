# 航空温控货物运输放行与温度偏差调查平台

基于React、Ant Design、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。无需后端，浏览器持久化演示数据。

## 功能

- 温控运输任务列表、关键词和状态筛选。
- 航段时间轴、温度曲线缩放、原始时间点定位与超限标记。
- 温度曲线、设备报告、包装确认和交接签字证据的版本管理。
- 温度超限自动/人工偏差、原因调查、影响评估和放行复核。
- 多角色签收、未核验证据与未关闭偏差放行拦截、完整报告导出。

## 统一版本记录

运输任务、温度偏差、证据版本和放行签署接在同一条统一版本线上（`Shipment.recordLedger` / `Shipment.version`），运输列表、偏差工作台和审计页显示同一个版本号。

- **证据换版级联**：常补证据或换设备报告时，同分类旧版本标记“已替代”；引用旧版本的偏差调查结论立即失效（`stale`），必须改选最新证据重新复核；放行前换版同步撤回已有放行签署，原意见与签署版本保留在签署历史中。
- **两窗口并发**：每个窗口带会话标识（侧边栏可见），所有保存都基于打开时看到的版本做乐观并发校验；后到一方看到冲突版本时保存被拦截，不能覆盖对方处置，需刷新到最新版本后重新处置，冲突进入审计。
- **写入失败恢复**：写入在克隆上完成，失败整体回滚到最后一个完整版本，并生成恢复计划（已完成项/未完成项）；恢复时重放已完成项、只补录未完成项，恢复基线被其它窗口推进时拒绝恢复。
- **放行后更正**：放行决定锚定版本号，放行后的证据更正必须填写原因，作为“原因版本”追加，不撤回、不覆盖原放行。
- 可在任务详情页用“模拟写入失败”注入单次故障，演示回滚与恢复流程。

```bash
npm install
npm run test:logic   # 统一版本逻辑冒烟测试（换版失效、签署撤回、冲突拦截、失败恢复、放行后更正）
npm run build
npm run dev
```
