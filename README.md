# 航空温控货物运输放行与温度偏差调查平台

基于React、Ant Design、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。无需后端，浏览器持久化演示数据。

## 功能

- 温控运输任务列表、关键词和状态筛选。
- 航段时间轴、温度曲线缩放、原始时间点定位与超限标记。
- **统一版本记录**：运输任务、温度偏差、证据版本、放行签署共用同一版本号（`shipment.version` / `VersionRecord`），运输列表、偏差工作台、审计页显示同一版本。
- 温度曲线、设备报告、包装确认和交接签字证据的版本管理（现行/已废止）。
- **证据换版联动**：同分类证据上传新版本后，引用旧版本的调查结论立即失效，受影响偏差回到“待重新复核”，原复核意见归档标记失效；放行签署同时撤回（原签署意见在历史中保留），已放行任务退回待放行。未引用该证据的结论继续有效。
- **放行后更正**：已放行任务补证据/换设备报告必须填写更正原因，作为原因版本另存并触发同一联动。
- **多窗口并发**：每个窗口按打开时的版本基线保存，后到一方检测到冲突版本即被拦截，记录“并发冲突”事件且不覆盖对方处置；跨窗口通过 `storage` 事件同步。
- **写入失败恢复**：下次写入可模拟失败，状态停在最后一个完整版本，仅登记未完成项；恢复时只补这一项，期间版本已推进则冲突拦截。
- 多角色签收、未核验证据与未关闭偏差放行拦截、完整报告导出。

端口为`18465`。

```bash
npm install
npm run build
npm run dev
```
